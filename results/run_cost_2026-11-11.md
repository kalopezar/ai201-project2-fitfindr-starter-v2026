# Measured cost of one FitFindr run

Measured 2026-11-11 local time (2026-11-12 UTC) against the local HTTP server.
The ten runs all used the same request, `vintage graphic tee under $30`, and
the default wardrobe.

## Method

Started `python serve.py` with `AI201_CACHE=0`, then sent ten sequential
`POST /ask` requests. For each request, used the server's JSONL record:

- `duration_ms` is the wall-clock request duration measured with
  `time.perf_counter()`, including MCP startup and model/network waits.
- Prompt and output tokens are the usage metadata reported by the model API,
  collected as per-request counter deltas.
- Model calls and cache hits are also per-request counter deltas. Cache was
  disabled, and every record confirms zero cache hits.

Thus, for this request and setup, one uncached run consumed an average of
**848.5 reported tokens** and took **7.95 seconds** end to end. Run 8 used
three model calls rather than two (a retry) and took 37.72 seconds; it remains
included in the average.

This is measured token usage and elapsed time, not a dollar invoice. The
application receives token counts but not billed USD from the model API, so no
USD amount is claimed.
